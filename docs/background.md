# 致一位無名者 — TXC 象棋引擎的還原背景

[返回專案首頁](../README.md) · [技術文件](technical-guide.md)

這個專案始於讓現代象棋程式與紅白機遊戲對弈的實驗。為了理解老遊戲的決策，研究逐步從棋盤記憶體與輸入擴展到 6502 搜尋子程序，最後形成可獨立執行的 C11 還原版。

原卡帶引擎以有限記憶體實現走法生成、迭代加深、局面評估與選擇性延伸。還原過程最值得保留的，是這些資料佈局和搜尋次序如何共同工作；對應位址及可驗證行為見 [引擎還原記錄](../analysis/engine_map.md)。

原首頁以「致一位無名者」紀念尚未確認身份的開發者。此處保留這份敬意，也把可驗證結果與歷史推測分開：目前資料不足以確認個人作者、其經歷或未署名的原因。

## 對原文效能敘述的更正

原首頁曾以「1.79 MHz 紅白機對 16 執行緒現代引擎」描述對局結果。儲存庫內 [對局方法與日誌](../comparison/README.md) 記錄的是現代電腦執行 TXC C DLL，對手為**單執行緒** ChineseChessAI 傳統引擎。因此毫秒數屬於 C 還原版，不代表卡帶原機耗時；也不能由這 14 局推論所有現代引擎的棋力。

原文將走法排序、延伸和增量評估直接判定為勝負根因，超出了已保存的實驗證據。它們是可研究的架構差異；要量化各自影響，仍需消融與更多對局。

有限測試顯示指定局面的著法、評分及節點追蹤相符，尚不能證明所有局面的每個決策都等價。原始文章仍可由 Git 歷史追溯，技術主張以目前 README 與報告為準。
